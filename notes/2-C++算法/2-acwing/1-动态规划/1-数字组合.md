# 278. 数字组合

给定 N 个正整数 A1,A2,…,AN，从中选出若干个数，使它们的和为 M，求有多少种选择方案。

**输入格式**

第一行包含两个整数 N 和 M。

第二行包含 N 个整数，表示 A1,A2,…,AN。

**输出格式**

包含一个整数，表示可选方案数。

**数据范围**

1≤N≤100,1≤M≤10000,1≤Ai≤1000.

答案保证在 int 范围内。

**输入样例：**

```
4 4
1 1 2 2
```

**输出样例：**

```
3
```

## 算法设计

算法设计：使用 **01 背包的方案数 DP**。

定义 `f[j]` 表示从前面若干个数中选取，和恰好为 `j` 的方案数，初始化 `f[0] = 1`。依次枚举每个数 `a[i]`，并将容量 `j` 从 `m` 倒序枚举，状态转移为：

```
f[j] += f[j - a[i]];
```

倒序枚举可以保证每个数最多使用一次，最终 `f[m]` 即为答案。

> 因为这是 **01 背包**，每个数只能选一次。倒序枚举可以避免当前 `a[i]` 被重复使用。
>
> 例如当前 `a[i] = 2`：
>
> 如果正序：
>
> ```
> f[2] += f[0];   // 使用了一次 2
> f[4] += f[2];   // 此时 f[2] 已经包含这个 2，相当于又使用一次
> ```
>
> 这样同一个 `2` 就可能被使用多次，变成了完全背包。
>
> 而倒序：
>
> ```
> f[4] += f[2];
> f[2] += f[0];
> ```
>
> 计算 `f[4]` 时，`f[2]` 还是处理当前 `2` 之前的旧值，因此当前这个数最多只会被选一次。
>
> 一句话记忆：**01 背包倒序，防止一个物品重复使用；完全背包正序，允许一个物品重复使用。**



## 代码实现

```cpp
#include <iostream>
using namespace std;
const int N = 1e4 + 10;
int f[N], a[110];

int main()
{
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i ++)
        cin >> a[i];
    f[0] = 1;
    for (int i = 1; i <= n; i ++)
    {
        for (int j = m; j >= a[i]; j --)
        {
            f[j] += f[j - a[i]]; 
        }
    }
    cout << f[m];
    
    return 0;
}
```
