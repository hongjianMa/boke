# **105. 从前序与中序遍历序列构造二叉树**

给定两个整数数组 `preorder` 和 `inorder`，其中 `preorder` 是二叉树的先序遍历，`inorder` 是同一棵树的中序遍历，请构造二叉树并返回其根节点。

## 算法设计
采用**递归 + 分治**构造二叉树。

具体思路如下：

1. 前序遍历的第一个元素 `pre[i]` 一定是当前子树的根节点。

2. 在中序遍历中找到根节点的位置 `p`。

3. 根节点左侧的元素属于左子树，右侧的元素属于右子树。

4. 令左子树节点数为 

   ```
   k = p - j
   ```

   ：

   - 左子树的前序区间从 `i + 1` 开始，共 `k` 个节点。
   - 右子树的前序区间从 `i + k + 1` 开始。

5. 递归构造左右子树，当节点数量 `n <= 0` 时返回空指针。

核心递归关系为：

```
r->left = creatNode(pre, i + 1, in, j, k);

r->right = creatNode(
    pre,
    i + k + 1,
    in,
    p + 1,
    n - k - 1
);
```

其中参数含义为：

- `i`：当前子树在前序遍历中的起始位置。
- `j`：当前子树在中序遍历中的起始位置。
- `n`：当前子树的节点数量。

由于每次递归都要在线性扫描中序数组查找根节点，最坏时间复杂度为 $O(n^2)$，递归栈空间复杂度为 $O(n)$。该方法默认树中节点值互不相同。

## 代码实现
```cpp
class Solution {
public:

    TreeNode *creatNode(vector<int> &pre, int i, vector<int> &in, int j, int n)
    {
        if (n <= 0) return NULL;
        TreeNode *r = new TreeNode(pre[i]);
        int p = j;
        // printf("%d", j);
        while(in[p] != pre[i]) p++;
        int k = p - j;
        r -> left = creatNode(pre, i+1, in, j, k);
        r ->right = creatNode(pre, i + k + 1, in, p + 1, n - k - 1);
        return r;
    }
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        int n = preorder.size();
        if (n == 1)
            return new TreeNode(preorder[0]);
        else
            return creatNode(preorder, 0, inorder, 0, n);
    }
};
```
