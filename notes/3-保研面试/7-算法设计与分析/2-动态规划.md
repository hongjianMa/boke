# 动态规划和贪心的区别
**基本思想不同**

- **动态规划**：把大问题拆成多个子问题，保存子问题的结果，综合比较后得到最优解。
- **贪心法**：每一步都选择当前看起来最优的方案，不考虑之后是否会出现更好的组合。

**是否保存子问题结果**

- **动态规划**：会记录已经计算过的子问题结果，避免重复计算。
- **贪心法**：通常不保存所有子问题结果，只关心当前选择。

**选择是否可以回头**

- **动态规划**：会比较多种可能的状态和方案，再确定最终最优解。
- **贪心法**：一旦做出选择，一般不再改变。

**适用条件不同**

- **动态规划**：通常要求问题具有**最优子结构**和**重叠子问题**。
- **贪心法**：除了最优子结构外，还要求具有更强的**贪心选择性质**，即“当前最优选择最终一定能导向整体最优”。

**时间和空间开销**

- **动态规划**：通常计算量和空间开销较大。
- **贪心法**：通常实现更简单，时间和空间开销更小。

**一句话记忆**

- **动态规划：把各种可能都算一算，再选最优。**
- **贪心法：每一步都选眼前最优，一路选到底**

# 最大连续子序列和
## 一、题目描述

给定一个整数数组，要求找出其中一个**连续子序列**，使这个子序列中所有元素的和最大，并输出这个最大值。

例如：

```
数组：-2  1  -3  4  -1  2  1  -5  4
```

其中最大连续子序列为：

```
4  -1  2  1
```

它们的和为：

```
4 + (-1) + 2 + 1 = 6
```

所以答案是：

```
6
```

------

## 二、算法分析

我们使用动态规划来解决。

### 1. 定义状态

设：

```
dp[i] = 以第 i 个元素结尾的最大连续子序列和
```

注意关键词是：

> **必须以 a[i] 结尾。**

例如当前元素是：

```
... -3  4
```

那么到了 `4` 的时候，有两种选择：

- 把 `4` 自己作为一个新的连续子序列。
- 把 `4` 接到前面的最大连续子序列后面。

因此：

```
dp[i] = max(a[i], dp[i-1] + a[i])
```

### 2. 为什么这样转移

假设：

```
a[i] = 4
dp[i-1] = -2
```

有两种选择：

```
继续前面的序列：-2 + 4 = 2
重新开始：4
```

显然选择：

```
4
```

也就是说：

> 如果前面的连续子序列对当前元素有“拖后腿”的作用，那就直接丢掉前面，从当前元素重新开始。

反过来，如果：

```
a[i] = 2
dp[i-1] = 3
```

那么：

```
继续前面的序列：3 + 2 = 5
重新开始：2
```

显然应该选择：

```
5
```

所以核心思想可以记成一句话：

> **前面的和如果有帮助就带上，没帮助就从当前位置重新开始。**

### 3. 举例推导

数组：

```
-2  1  -3  4  -1  2  1
```

计算过程：

| `a[i]` | `dp[i]` | 含义                          |
| ------ | ------- | ----------------------------- |
| -2     | -2      | 只能选 -2                     |
| 1      | 1       | `max(1, -2+1)`                |
| -3     | -2      | `max(-3, 1-3)`                |
| 4      | 4       | 前面的 -2 不要，从 4 重新开始 |
| -1     | 3       | `4 + (-1)`                    |
| 2      | 5       | `3 + 2`                       |
| 1      | 6       | `5 + 1`                       |

因此最大值是：

```
6
```

------

## 三、简易代码示例

```cpp
#include <iostream>
#include <algorithm>
using namespace std;


int main()
{
    int n;
    cin >> n;


    int a[1000];


    for (int i = 0; i < n; i++)
        cin >> a[i];


    int dp[1000];


    // 第一个位置
    dp[0] = a[0];


    // 记录最终答案
    int ans = dp[0];


    for (int i = 1; i < n; i++)
    {
        // 要么接上前面的序列
        // 要么从当前元素重新开始
        dp[i] = max(a[i], dp[i - 1] + a[i]);


        ans = max(ans, dp[i]);
    }


    cout << ans << endl;


    return 0;
}
```

最需要记住的就是这句：

```cpp
dp[i] = max(a[i], dp[i - 1] + a[i]);
```

含义就是：

> **对于当前 `a[i]`，要么自己重新开一个连续子序列，要么接在前面的最优连续子序列后面，谁大选谁。**
