# 动态规划和贪心的区别
**基本思想不同**

- **动态规划**：把大问题拆成多个子问题，保存子问题的结果，综合比较后得到最优解。
- **贪心法**：每一步都选择当前看起来最优的方案，不考虑之后是否会出现更好的组合。

**是否保存子问题结果**

- **动态规划**：会记录已经计算过的子问题结果，避免重复计算。
- **贪心法**：通常不保存所有子问题结果，只关心当前选择。

**选择是否可以回头**

- **动态规划**：会比较多种可能的状态和方案，再确定最终最优解。
- **贪心法**：一旦做出选择，一般不再改变。

**适用条件不同**

- **动态规划**：通常要求问题具有**最优子结构**和**重叠子问题**。
- **贪心法**：除了最优子结构外，还要求具有更强的**贪心选择性质**，即“当前最优选择最终一定能导向整体最优”。

**时间和空间开销**

- **动态规划**：通常计算量和空间开销较大。
- **贪心法**：通常实现更简单，时间和空间开销更小。

**一句话记忆**

- **动态规划：把各种可能都算一算，再选最优。**
- **贪心法：每一步都选眼前最优，一路选到底**

# 最大连续子序列和
## 一、题目描述

给定一个整数数组，要求找出其中一个**连续子序列**，使这个子序列中所有元素的和最大，并输出这个最大值。

例如：

```
数组：-2  1  -3  4  -1  2  1  -5  4
```

其中最大连续子序列为：

```
4  -1  2  1
```

它们的和为：

```
4 + (-1) + 2 + 1 = 6
```

所以答案是：

```
6
```

------

## 二、算法分析

我们使用动态规划来解决。

### 1. 定义状态

设：

```
dp[i] = 以第 i 个元素结尾的最大连续子序列和
```

注意关键词是：

> **必须以 a[i] 结尾。**

例如当前元素是：

```
... -3  4
```

那么到了 `4` 的时候，有两种选择：

- 把 `4` 自己作为一个新的连续子序列。
- 把 `4` 接到前面的最大连续子序列后面。

因此：

```
dp[i] = max(a[i], dp[i-1] + a[i])
```

### 2. 为什么这样转移

假设：

```
a[i] = 4
dp[i-1] = -2
```

有两种选择：

```
继续前面的序列：-2 + 4 = 2
重新开始：4
```

显然选择：

```
4
```

也就是说：

> 如果前面的连续子序列对当前元素有“拖后腿”的作用，那就直接丢掉前面，从当前元素重新开始。

反过来，如果：

```
a[i] = 2
dp[i-1] = 3
```

那么：

```
继续前面的序列：3 + 2 = 5
重新开始：2
```

显然应该选择：

```
5
```

所以核心思想可以记成一句话：

> **前面的和如果有帮助就带上，没帮助就从当前位置重新开始。**

### 3. 举例推导

数组：

```
-2  1  -3  4  -1  2  1
```

计算过程：

| `a[i]` | `dp[i]` | 含义                          |
| ------ | ------- | ----------------------------- |
| -2     | -2      | 只能选 -2                     |
| 1      | 1       | `max(1, -2+1)`                |
| -3     | -2      | `max(-3, 1-3)`                |
| 4      | 4       | 前面的 -2 不要，从 4 重新开始 |
| -1     | 3       | `4 + (-1)`                    |
| 2      | 5       | `3 + 2`                       |
| 1      | 6       | `5 + 1`                       |

因此最大值是：

```
6
```

------

## 三、简易代码示例

```cpp
#include <iostream>
#include <algorithm>
using namespace std;


int main()
{
    int n;
    cin >> n;


    int a[1000];


    for (int i = 0; i < n; i++)
        cin >> a[i];


    int dp[1000];


    // 第一个位置
    dp[0] = a[0];


    // 记录最终答案
    int ans = dp[0];


    for (int i = 1; i < n; i++)
    {
        // 要么接上前面的序列
        // 要么从当前元素重新开始
        dp[i] = max(a[i], dp[i - 1] + a[i]);


        ans = max(ans, dp[i]);
    }


    cout << ans << endl;


    return 0;
}
```

最需要记住的就是这句：

```cpp
dp[i] = max(a[i], dp[i - 1] + a[i]);
```

含义就是：

> **对于当前 `a[i]`，要么自己重新开一个连续子序列，要么接在前面的最优连续子序列后面，谁大选谁。**


# 最长递增子序列
## 一、题目描述

给定一个整数序列，要求找出其中**最长的严格递增子序列**，并输出这个子序列的长度。

例如：

```
序列：10  9  2  5  3  7  101  18
```

其中一个最长递增子序列为：

```
2  3  7  18
```

长度为：

```
4
```

需要注意：

> **子序列不要求连续，只要求保持原来的先后顺序。**

例如：

```
2  3  7  18
```

在原数组中虽然不是连续的，但顺序没有改变，所以是合法的子序列。

------

## 二、算法分析

### 1. dp 的设计

定义：

```
dp[i] = 以第 i 个元素 a[i] 结尾的最长递增子序列长度
```

关键词是：

> **必须以 `a[i]` 结尾。**

例如：

```
序列：2  5  3  7
```

对于 `7` 来说，我们需要看看它前面有哪些比它小的数：

```
2 < 7
5 < 7
3 < 7
```

那么 `7` 可以接在这些元素对应的递增子序列后面。

因此，对于每个 `i`，枚举它前面的 `j`：

```
if (a[j] < a[i])
    dp[i] = max(dp[i], dp[j] + 1);
```

也就是说：

> 如果 `a[j] < a[i]`，那么 `a[i]` 就可以接到以 `a[j]` 结尾的递增子序列后面。

------

### 2. 初始状态

每个元素至少都可以自己构成一个长度为 `1` 的递增子序列，因此：

```
dp[i] = 1
```

例如：

```
10  9  2  5
```

一开始：

```
dp = 1  1  1  1
```

然后再逐渐更新。

------

### 3. 举例理解

假设序列：

```
1  4  2  3
```

#### `a[0] = 1`

只有自己：

```
dp[0] = 1
```

#### `a[1] = 4`

因为：

```
1 < 4
```

所以可以：

```
1 → 4
```

因此：

```
dp[1] = dp[0] + 1 = 2
```

#### `a[2] = 2`

因为：

```
1 < 2
```

所以：

```
1 → 2
```

因此：

```
dp[2] = 2
```

#### `a[3] = 3`

前面：

```
1 < 3
2 < 3
```

其中接在 `2` 后面最好：

```
1 → 2 → 3
```

所以：

```
dp[3] = 3
```

最终：

```
dp = 1  2  2  3
```

因此最长递增子序列长度为：

```
3
```

------

### 4. 状态转移总结

对于每个 `i`：

1. 先令 `dp[i] = 1`。
2. 枚举前面的所有 `j`。
3. 如果 `a[j] < a[i]`，说明 `a[i]` 可以接在 `a[j]` 后面。
4. 更新：

```
dp[i] = max(dp[i], dp[j] + 1);
```

最后答案不是单独的 `dp[n-1]`，而是：

```
max(dp[0], dp[1], ..., dp[n-1])
```

因为最长递增子序列**不一定以最后一个元素结尾**。

------

### 5. 复杂度

有两层循环：

```
for (int i = 0; i < n; i++)
    for (int j = 0; j < i; j++)
```

所以：

- **时间复杂度：O(n²)**
- **空间复杂度：O(n)**

其中 `dp` 数组需要存储 `n` 个状态。

------

## 三、简易代码示例

```cpp
#include <iostream>
#include <algorithm>
using namespace std;


int main()
{
    int n;
    cin >> n;


    int a[1000];
    int dp[1000];


    for (int i = 0; i < n; i++)
        cin >> a[i];


    int ans = 0;


    for (int i = 0; i < n; i++)
    {
        // 每个元素自己至少构成长度为1的子序列
        dp[i] = 1;


        // 枚举i前面的所有元素
        for (int j = 0; j < i; j++)
        {
            // 如果a[i]可以接在a[j]后面
            if (a[j] < a[i])
            {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }


        ans = max(ans, dp[i]);
    }


    cout << ans << endl;


    return 0;
}
```

最核心的代码就是：

```cpp
if (a[j] < a[i])
    dp[i] = max(dp[i], dp[j] + 1);
```

可以简单记成：

> **看当前位置 `a[i]` 前面有哪些比它小的数，找到其中最长的递增子序列，再把 `a[i]` 接到后面，长度加 1。**
