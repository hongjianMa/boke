# 动态规划和贪心的区别
**基本思想不同**

- **动态规划**：把大问题拆成多个子问题，保存子问题的结果，综合比较后得到最优解。
- **贪心法**：每一步都选择当前看起来最优的方案，不考虑之后是否会出现更好的组合。

**是否保存子问题结果**

- **动态规划**：会记录已经计算过的子问题结果，避免重复计算。
- **贪心法**：通常不保存所有子问题结果，只关心当前选择。

**选择是否可以回头**

- **动态规划**：会比较多种可能的状态和方案，再确定最终最优解。
- **贪心法**：一旦做出选择，一般不再改变。

**适用条件不同**

- **动态规划**：通常要求问题具有**最优子结构**和**重叠子问题**。
- **贪心法**：除了最优子结构外，还要求具有更强的**贪心选择性质**，即“当前最优选择最终一定能导向整体最优”。

**时间和空间开销**

- **动态规划**：通常计算量和空间开销较大。
- **贪心法**：通常实现更简单，时间和空间开销更小。

**一句话记忆**

- **动态规划：把各种可能都算一算，再选最优。**
- **贪心法：每一步都选眼前最优，一路选到底**

# 最大连续子序列和
## 一、题目描述

给定一个整数数组，要求找出其中一个**连续子序列**，使这个子序列中所有元素的和最大，并输出这个最大值。

例如：

```
数组：-2  1  -3  4  -1  2  1  -5  4
```

其中最大连续子序列为：

```
4  -1  2  1
```

它们的和为：

```
4 + (-1) + 2 + 1 = 6
```

所以答案是：

```
6
```

------

## 二、算法分析

我们使用动态规划来解决。

### 1. 定义状态

设：

```
dp[i] = 以第 i 个元素结尾的最大连续子序列和
```

注意关键词是：

> **必须以 a[i] 结尾。**

例如当前元素是：

```
... -3  4
```

那么到了 `4` 的时候，有两种选择：

- 把 `4` 自己作为一个新的连续子序列。
- 把 `4` 接到前面的最大连续子序列后面。

因此：

```
dp[i] = max(a[i], dp[i-1] + a[i])
```

### 2. 为什么这样转移

假设：

```
a[i] = 4
dp[i-1] = -2
```

有两种选择：

```
继续前面的序列：-2 + 4 = 2
重新开始：4
```

显然选择：

```
4
```

也就是说：

> 如果前面的连续子序列对当前元素有“拖后腿”的作用，那就直接丢掉前面，从当前元素重新开始。

反过来，如果：

```
a[i] = 2
dp[i-1] = 3
```

那么：

```
继续前面的序列：3 + 2 = 5
重新开始：2
```

显然应该选择：

```
5
```

所以核心思想可以记成一句话：

> **前面的和如果有帮助就带上，没帮助就从当前位置重新开始。**

### 3. 举例推导

数组：

```
-2  1  -3  4  -1  2  1
```

计算过程：

| `a[i]` | `dp[i]` | 含义                          |
| ------ | ------- | ----------------------------- |
| -2     | -2      | 只能选 -2                     |
| 1      | 1       | `max(1, -2+1)`                |
| -3     | -2      | `max(-3, 1-3)`                |
| 4      | 4       | 前面的 -2 不要，从 4 重新开始 |
| -1     | 3       | `4 + (-1)`                    |
| 2      | 5       | `3 + 2`                       |
| 1      | 6       | `5 + 1`                       |

因此最大值是：

```
6
```

------

## 三、简易代码示例

```cpp
#include <iostream>
#include <algorithm>
using namespace std;


int main()
{
    int n;
    cin >> n;


    int a[1000];


    for (int i = 0; i < n; i++)
        cin >> a[i];


    int dp[1000];


    // 第一个位置
    dp[0] = a[0];


    // 记录最终答案
    int ans = dp[0];


    for (int i = 1; i < n; i++)
    {
        // 要么接上前面的序列
        // 要么从当前元素重新开始
        dp[i] = max(a[i], dp[i - 1] + a[i]);


        ans = max(ans, dp[i]);
    }


    cout << ans << endl;


    return 0;
}
```

最需要记住的就是这句：

```cpp
dp[i] = max(a[i], dp[i - 1] + a[i]);
```

含义就是：

> **对于当前 `a[i]`，要么自己重新开一个连续子序列，要么接在前面的最优连续子序列后面，谁大选谁。**


# 最长递增子序列
## 一、题目描述

给定一个整数序列，要求找出其中**最长的严格递增子序列**，并输出这个子序列的长度。

例如：

```
序列：10  9  2  5  3  7  101  18
```

其中一个最长递增子序列为：

```
2  3  7  18
```

长度为：

```
4
```

需要注意：

> **子序列不要求连续，只要求保持原来的先后顺序。**

例如：

```
2  3  7  18
```

在原数组中虽然不是连续的，但顺序没有改变，所以是合法的子序列。

------

## 二、算法分析

### 1. dp 的设计

定义：

```
dp[i] = 以第 i 个元素 a[i] 结尾的最长递增子序列长度
```

关键词是：

> **必须以 `a[i]` 结尾。**

例如：

```
序列：2  5  3  7
```

对于 `7` 来说，我们需要看看它前面有哪些比它小的数：

```
2 < 7
5 < 7
3 < 7
```

那么 `7` 可以接在这些元素对应的递增子序列后面。

因此，对于每个 `i`，枚举它前面的 `j`：

```
if (a[j] < a[i])
    dp[i] = max(dp[i], dp[j] + 1);
```

也就是说：

> 如果 `a[j] < a[i]`，那么 `a[i]` 就可以接到以 `a[j]` 结尾的递增子序列后面。

------

### 2. 初始状态

每个元素至少都可以自己构成一个长度为 `1` 的递增子序列，因此：

```
dp[i] = 1
```

例如：

```
10  9  2  5
```

一开始：

```
dp = 1  1  1  1
```

然后再逐渐更新。

------

### 3. 举例理解

假设序列：

```
1  4  2  3
```

#### `a[0] = 1`

只有自己：

```
dp[0] = 1
```

#### `a[1] = 4`

因为：

```
1 < 4
```

所以可以：

```
1 → 4
```

因此：

```
dp[1] = dp[0] + 1 = 2
```

#### `a[2] = 2`

因为：

```
1 < 2
```

所以：

```
1 → 2
```

因此：

```
dp[2] = 2
```

#### `a[3] = 3`

前面：

```
1 < 3
2 < 3
```

其中接在 `2` 后面最好：

```
1 → 2 → 3
```

所以：

```
dp[3] = 3
```

最终：

```
dp = 1  2  2  3
```

因此最长递增子序列长度为：

```
3
```

------

### 4. 状态转移总结

对于每个 `i`：

1. 先令 `dp[i] = 1`。
2. 枚举前面的所有 `j`。
3. 如果 `a[j] < a[i]`，说明 `a[i]` 可以接在 `a[j]` 后面。
4. 更新：

```
dp[i] = max(dp[i], dp[j] + 1);
```

最后答案不是单独的 `dp[n-1]`，而是：

```
max(dp[0], dp[1], ..., dp[n-1])
```

因为最长递增子序列**不一定以最后一个元素结尾**。

------

### 5. 复杂度

有两层循环：

```
for (int i = 0; i < n; i++)
    for (int j = 0; j < i; j++)
```

所以：

- **时间复杂度：O(n²)**
- **空间复杂度：O(n)**

其中 `dp` 数组需要存储 `n` 个状态。

------

## 三、简易代码示例

```cpp
#include <iostream>
#include <algorithm>
using namespace std;


int main()
{
    int n;
    cin >> n;


    int a[1000];
    int dp[1000];


    for (int i = 0; i < n; i++)
        cin >> a[i];


    int ans = 0;


    for (int i = 0; i < n; i++)
    {
        // 每个元素自己至少构成长度为1的子序列
        dp[i] = 1;


        // 枚举i前面的所有元素
        for (int j = 0; j < i; j++)
        {
            // 如果a[i]可以接在a[j]后面
            if (a[j] < a[i])
            {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }


        ans = max(ans, dp[i]);
    }


    cout << ans << endl;


    return 0;
}
```

最核心的代码就是：

```cpp
if (a[j] < a[i])
    dp[i] = max(dp[i], dp[j] + 1);
```

可以简单记成：

> **看当前位置 `a[i]` 前面有哪些比它小的数，找到其中最长的递增子序列，再把 `a[i]` 接到后面，长度加 1。**

# 三角形的最小路径和
## 一、题目描述

给定一个数字三角形，从**最上面的数字出发**，每次只能走到下一行中与当前位置相邻的两个数字，直到走到最底层。

要求找到一条路径，使得路径上的数字之和最小。

例如：

```
      2
     3 4
    6 5 7
   4 1 8 3
```

一条最小路径为：

```
2 → 3 → 5 → 1
```

路径和为：

```
2 + 3 + 5 + 1 = 11
```

所以答案是：

```
11
```

------

## 二、算法分析

### 1. dp 的设计

可以从**上往下**进行动态规划。

定义：

```
dp[i][j] = 从三角形顶部走到第 i 行第 j 个位置的最小路径和
```

例如：

```
      2
     3 4
    6 5 7
```

对于中间的 `5` 来说，它可以从上一层的：

```
3 → 5
4 → 5
```

两条路径走过来。

所以我们只需要选择其中路径和较小的那一个。

因此状态转移为：

```
dp[i][j] = min(dp[i - 1][j - 1], dp[i - 1][j]) + a[i][j];
```

也就是：

> **当前点的最小路径和 = 上面两个能走到当前位置的点中较小的路径和 + 当前数字。**

------

### 2. 边界情况

三角形的最左边和最右边比较特殊。

例如：

```
      2
     3 4
    6 5 7
```

对于最左边的 `6`，它只能从 `3` 走下来：

```
dp[i][0] = dp[i - 1][0] + a[i][0];
```

对于最右边的 `7`，它只能从 `4` 走下来：

```
dp[i][i] = dp[i - 1][i - 1] + a[i][i];
```

而中间位置才有两个选择：

```
dp[i][j] = min(dp[i - 1][j - 1], dp[i - 1][j]) + a[i][j];
```

------

### 3. 举例计算

原三角形：

```
      2
     3 4
    6 5 7
   4 1 8 3
```

第一行：

```
2
```

所以：

```
dp[0][0] = 2
```

第二行：

```
5  6
```

因为：

```
2 + 3 = 5
2 + 4 = 6
```

第三行：

```
11  10  13
```

其中中间的 `5`：

```
min(5, 6) + 5 = 10
```

第四行：

```
15  11  18  16
```

最后一行的最小值为：

```
11
```

因此最终答案就是：

```
min(dp[n - 1][0], dp[n - 1][1], ..., dp[n - 1][n - 1])
```

注意：

> 最终不一定走到最左边或最右边，所以需要在最后一行中找最小值。

------

### 4. 复杂度

三角形一共有大约：

```
1 + 2 + 3 + ... + n
```

也就是 `O(n²)` 个数字，每个位置只需要计算一次。

因此：

- **时间复杂度：O(n²)**
- **空间复杂度：O(n²)**

如果进一步使用一维数组进行空间优化，可以把空间复杂度降低到：

```
O(n)
```

------

## 三、简易代码示例

```cpp
#include <iostream>
#include <algorithm>
using namespace std;


int main()
{
    int n;
    cin >> n;


    int a[100][100];
    int dp[100][100];


    // 输入三角形
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j <= i; j++)
        {
            cin >> a[i][j];
        }
    }


    // 起点
    dp[0][0] = a[0][0];


    for (int i = 1; i < n; i++)
    {
        // 最左边
        dp[i][0] = dp[i - 1][0] + a[i][0];


        // 中间位置
        for (int j = 1; j < i; j++)
        {
            dp[i][j] =
                min(dp[i - 1][j - 1], dp[i - 1][j])
                + a[i][j];
        }


        // 最右边
        dp[i][i] = dp[i - 1][i - 1] + a[i][i];
    }


    // 在最后一行找最小值
    int ans = dp[n - 1][0];


    for (int j = 1; j < n; j++)
    {
        ans = min(ans, dp[n - 1][j]);
    }


    cout << ans << endl;


    return 0;
}
```

最核心的状态转移可以记成：

```cpp
dp[i][j] =
    min(dp[i - 1][j - 1], dp[i - 1][j])
    + a[i][j];
```

一句话理解就是：**走到当前位置时，看上一层哪条路的路径和更小，就从哪条路走过来，再加上当前位置的数字。**

# 最长公共子序列
## 一、题目描述

给定两个字符串，要求找出它们的**最长公共子序列**，并求出这个子序列的长度。

例如：

```
字符串1：abcde
字符串2：ace
```

它们的公共子序列有：

```
a
c
e
ac
ae
ce
ace
```

其中最长的是：

```
ace
```

所以最长公共子序列的长度为：

```
3
```

需要注意：

> **子序列不要求连续，但必须保持字符原来的先后顺序。**

例如 `abcde` 中：

```
ace
```

虽然 `a、c、e` 不连续，但是顺序没有改变，所以是一个合法的子序列。

------

## 二、算法分析

### 1. dp 的设计

假设有两个字符串：

```
s1 = abcde
s2 = ace
```

定义：

```
dp[i][j] = s1的前i个字符 和 s2的前j个字符 的最长公共子序列长度
```

例如：

```
dp[3][2]
```

表示：

```
s1前3个字符：abc
s2前2个字符：ac
```

它们的最长公共子序列是：

```
ac
```

所以：

```
dp[3][2] = 2
```

------

### 2. 状态转移

对于当前位置：

```
s1[i - 1]
s2[j - 1]
```

有两种情况。

#### 情况一：两个字符相同

如果：

```
s1[i - 1] == s2[j - 1]
```

说明这个字符可以加入公共子序列。

因此：

```
dp[i][j] = dp[i - 1][j - 1] + 1;
```

例如：

```
abc
ac
```

最后两个字符都是：

```
c
```

那么只需要看：

```
ab
a
```

的最长公共子序列长度，然后再加上这个 `c`。

因此：

```
dp[3][2] = dp[2][1] + 1
```

------

#### 情况二：两个字符不同

如果：

```
s1[i - 1] != s2[j - 1]
```

说明这两个字符不能同时加入公共子序列。

这时候有两种选择：

```
不要 s1 当前字符
或者
不要 s2 当前字符
```

分别对应：

```
dp[i - 1][j]
```

和：

```
dp[i][j - 1]
```

选择其中较大的：

```
dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
```

------

### 3. 核心状态转移

所以整个状态转移可以写成：

```
if (s1[i - 1] == s2[j - 1])
{
    dp[i][j] = dp[i - 1][j - 1] + 1;
}
else
{
    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
}
```

可以简单记忆为：

> **相同：左上角 + 1；不同：上边和左边取最大。**

------

### 4. 为什么 dp 要多开一行一列

假设：

```
s1 = abc
s2 = ac
```

我们通常定义：

```
dp[0][j] = 0
dp[i][0] = 0
```

因为一个字符串和**空字符串**的最长公共子序列长度一定是 `0`。

所以 DP 表大概是：

|      | 空   | a    | c    |
| ---- | ---- | ---- | ---- |
| 空   | 0    | 0    | 0    |
| a    | 0    | 1    | 1    |
| b    | 0    | 1    | 1    |
| c    | 0    | 1    | 2    |

最终：

```
dp[3][2] = 2
```

因此最长公共子序列是：

```
ac
```

长度为 `2`。

------

### 5. 复杂度

假设两个字符串的长度分别为：

```
n 和 m
```

需要使用两层循环：

```
for (int i = 1; i <= n; i++)
{
    for (int j = 1; j <= m; j++)
```

因此：

- **时间复杂度：O(n × m)**
- **空间复杂度：O(n × m)**

因为需要一个 `n × m` 大小的二维 `dp` 数组。

------

## 三、简易代码示例

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;


int main()
{
    string s1, s2;
    cin >> s1 >> s2;


    int n = s1.size();
    int m = s2.size();


    int dp[1000][1000] = {0};


    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
        {
            // 当前两个字符相同
            if (s1[i - 1] == s2[j - 1])
            {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            }
            // 当前两个字符不同
            else
            {
                dp[i][j] = max(dp[i - 1][j],
                               dp[i][j - 1]);
            }
        }
    }


    cout << dp[n][m] << endl;


    return 0;
}
```

最核心的代码就是：

```cpp
if (s1[i - 1] == s2[j - 1])
    dp[i][j] = dp[i - 1][j - 1] + 1;
else
    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
```

一句话记忆：**两个字符相同，就把它加入公共子序列，取左上角加 1；两个字符不同，就舍弃其中一个字符，取上边和左边的最大值。**

# 编辑距离

## 一、题目描述

给定两个字符串 `word1` 和 `word2`，允许对 `word1` 进行以下三种操作：

1. **插入**一个字符。
2. **删除**一个字符。
3. **替换**一个字符。

要求计算：至少需要多少次操作，才能把 `word1` 变成 `word2`。

例如：

```
word1 = "horse"
word2 = "ros"
```

一种转换方式为：

```
horse
→ rorse    替换 h 为 r
→ rose     删除 r
→ ros      删除 e
```

一共进行了 `3` 次操作，所以编辑距离为：

```
3
```

------

## 二、算法分析

### 1. dp 的设计

假设两个字符串分别为：

```
s1 = horse
s2 = ros
```

定义：

```
dp[i][j] = 把 s1 的前 i 个字符变成 s2 的前 j 个字符所需要的最少操作次数
```

例如：

```
dp[3][2]
```

表示把：

```
s1 前3个字符：hor
```

转换成：

```
s2 前2个字符：ro
```

所需要的最少操作次数。

------

### 2. 初始状态

如果 `s2` 是空字符串：

```
dp[i][0] = i
```

因为要把长度为 `i` 的字符串变成空字符串，只能把所有字符删除。

例如：

```
abc → ""
```

需要删除 `3` 次。

所以：

```
dp[3][0] = 3
```

同理，如果 `s1` 是空字符串：

```
dp[0][j] = j
```

因为需要插入 `j` 个字符。

例如：

```
"" → abc
```

需要插入 `3` 次。

------

### 3. 当前两个字符相同

比较：

```
s1[i - 1]
s2[j - 1]
```

如果两个字符相同，就不需要额外操作。

例如：

```
abc
adc
  ↑
```

最后一个字符都是 `c`。

那么问题就变成：

> 把前面的 `ab` 变成 `ad` 需要多少次操作。

所以：

```
dp[i][j] = dp[i - 1][j - 1];
```

简单来说：

> **字符相同，不操作，直接看左上角。**

------

### 4. 当前两个字符不同

如果：

```
s1[i - 1] != s2[j - 1]
```

那么有三种操作可以选择：

#### ① 删除

把 `s1` 当前字符删除：

```
dp[i - 1][j] + 1
```

例如：

```
abc → ab
```

删除 `c`。

------

#### ② 插入

给 `s1` 插入一个字符，使它能够匹配 `s2` 当前字符：

```
dp[i][j - 1] + 1
```

例如：

```
ab → abc
```

插入 `c`。

------

#### ③ 替换

直接把 `s1` 当前字符替换成 `s2` 当前字符：

```
dp[i - 1][j - 1] + 1
```

例如：

```
abc → abd
```

把 `c` 替换成 `d`。

------

因此三个方案取最小值：

```
dp[i][j] = min({
    dp[i - 1][j],       // 删除
    dp[i][j - 1],       // 插入
    dp[i - 1][j - 1]    // 替换
}) + 1;
```

所以状态转移可以总结为：

```
if (s1[i - 1] == s2[j - 1])
{
    dp[i][j] = dp[i - 1][j - 1];
}
else
{
    dp[i][j] = min({
        dp[i - 1][j],
        dp[i][j - 1],
        dp[i - 1][j - 1]
    }) + 1;
}
```

可以简单记成：

> **相同看左上，不同看左、上、左上，取最小再加 1。**

其中：

```
上：   删除
左：   插入
左上： 替换
```

------

### 5. 举个简单例子

假设：

```
s1 = cat
s2 = cut
```

`c` 和 `c` 相同，不操作。

`a` 和 `u` 不同，可以直接替换：

```
cat
↓
cut
```

`t` 和 `t` 相同。

所以只需要：

```
1 次操作
```

即：

```
编辑距离 = 1
```

------

### 6. 复杂度

假设：

```
s1 长度为 n
s2 长度为 m
```

需要遍历一个 `n × m` 的二维 `dp` 数组，因此：

- **时间复杂度：O(n × m)**
- **空间复杂度：O(n × m)**

因为需要保存一个二维 `dp` 表。

------

## 三、简易代码示例

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;


int main()
{
    string s1, s2;
    cin >> s1 >> s2;


    int n = s1.size();
    int m = s2.size();


    int dp[1000][1000];


    // s1变成空字符串：全部删除
    for (int i = 0; i <= n; i++)
    {
        dp[i][0] = i;
    }


    // 空字符串变成s2：全部插入
    for (int j = 0; j <= m; j++)
    {
        dp[0][j] = j;
    }


    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
        {
            // 当前字符相同
            if (s1[i - 1] == s2[j - 1])
            {
                dp[i][j] = dp[i - 1][j - 1];
            }
            // 当前字符不同
            else
            {
                dp[i][j] = min({
                    dp[i - 1][j],      // 删除
                    dp[i][j - 1],      // 插入
                    dp[i - 1][j - 1]   // 替换
                }) + 1;
            }
        }
    }


    cout << dp[n][m] << endl;


    return 0;
}
```

最核心的内容可以记成：

```cpp
if (s1[i - 1] == s2[j - 1])
    dp[i][j] = dp[i - 1][j - 1];
else
    dp[i][j] = min({
        dp[i - 1][j],
        dp[i][j - 1],
        dp[i - 1][j - 1]
    }) + 1;
```

一句话记忆：**编辑距离就是把两个字符串从前往后比较，字符相同就不用操作；字符不同就在“插入、删除、替换”三种方案中选择操作次数最少的一种。**

# 矩阵连乘

## 一、题目描述

给定一串可以依次相乘的矩阵：

```
A1 × A2 × A3 × ... × An
```

矩阵乘法满足**结合律**，所以可以采用不同的加括号方式。

例如：

```
A1 × A2 × A3
```

可以写成：

```
(A1 × A2) × A3
```

也可以写成：

```
A1 × (A2 × A3)
```

虽然最后得到的矩阵相同，但是两种计算顺序需要的**标量乘法次数可能完全不同**。

------

### 举个例子

假设：

```
A1：10 × 100
A2：100 × 5
A3：5 × 50
```

第一种方式：

```
(A1 × A2) × A3
```

先计算：

```
10×100 乘 100×5
```

需要：

```
10 × 100 × 5 = 5000 次
```

得到一个：

```
10 × 5
```

的矩阵。

然后：

```
10×5 乘 5×50
```

需要：

```
10 × 5 × 50 = 2500 次
```

总次数：

```
5000 + 2500 = 7500
```

而第二种方式：

```
A1 × (A2 × A3)
```

先算：

```
100 × 5 × 50 = 25000
```

再算：

```
10 × 100 × 50 = 50000
```

总次数：

```
75000
```

所以不同的加括号方式，计算量可能差很多。

**矩阵连乘问题就是：找到一种最优的加括号方式，使矩阵乘法次数最少。**

------

# 二、算法分析

## 1. dp 的设计

假设有 `n` 个矩阵：

```
A1, A2, A3, ..., An
```

定义：

```
dp[i][j] = 计算 Ai × Ai+1 × ... × Aj 所需要的最少乘法次数
```

例如：

```
dp[2][4]
```

表示计算：

```
A2 × A3 × A4
```

所需要的最少乘法次数。

------

## 2. 为什么需要枚举分割点

假设现在要求：

```
A1 × A2 × A3 × A4
```

我们可以在不同位置把它分成左右两部分。

例如在 `A1` 后面分：

```
A1 × (A2 × A3 × A4)
```

在 `A2` 后面分：

```
(A1 × A2) × (A3 × A4)
```

在 `A3` 后面分：

```
(A1 × A2 × A3) × A4
```

所以对于：

```
Ai × ... × Aj
```

我们枚举一个位置 `k`：

```
i <= k < j
```

把整个问题拆成：

```
Ai ... Ak
```

和：

```
Ak+1 ... Aj
```

两个子问题。

------

## 3. 矩阵大小如何表示

假设有一个数组：

```
p[]
```

如果：

```
A1：p[0] × p[1]
A2：p[1] × p[2]
A3：p[2] × p[3]
...
```

那么：

```
Ai 的大小 = p[i-1] × p[i]
```

例如：

```
p = {10, 100, 5, 50}
```

就表示：

```
A1 = 10 × 100
A2 = 100 × 5
A3 = 5 × 50
```

------

## 4. 状态转移

假设我们在 `k` 的位置分割：

```
Ai ... Ak | Ak+1 ... Aj
```

那么总计算次数分成三部分。

### 第一部分：计算左边

```
dp[i][k]
```

### 第二部分：计算右边

```
dp[k+1][j]
```

### 第三部分：把左右两个结果矩阵相乘

左边最终得到的矩阵大小为：

```
p[i-1] × p[k]
```

右边最终得到：

```
p[k] × p[j]
```

两个矩阵相乘需要：

```
p[i-1] × p[k] × p[j]
```

次标量乘法。

因此：

```
dp[i][j] = min(
    dp[i][k]
    + dp[k + 1][j]
    + p[i - 1] * p[k] * p[j]
);
```

其中 `k` 要从：

```
i 到 j-1
```

全部枚举一遍。

------

## 5. 核心思想

比如要求：

```
A1 × A2 × A3 × A4
```

我们不知道在哪里加最后一个括号最好。

因此：

```
A1 | A2 A3 A4


A1 A2 | A3 A4


A1 A2 A3 | A4
```

把所有可能的分割位置都试一下，选择代价最小的。

可以记成一句话：

> **枚举最后一次矩阵乘法在哪里分开，左边取最优，右边取最优，再加上左右两部分相乘的代价。**

------

## 6. 初始状态

如果只有一个矩阵：

```
Ai
```

根本不需要做矩阵乘法。

所以：

```
dp[i][i] = 0;
```

例如：

```
dp[1][1] = 0
dp[2][2] = 0
dp[3][3] = 0
```

------

## 7. 为什么要按区间长度计算

矩阵连乘属于典型的**区间动态规划**。

因为：

```
dp[i][j]
```

需要：

```
dp[i][k]
dp[k+1][j]
```

这些更短区间的结果。

所以需要：

> **先计算短区间，再计算长区间。**

例如先计算：

```
长度1：
A1
A2
A3
A4
```

然后：

```
长度2：
A1A2
A2A3
A3A4
```

再：

```
长度3：
A1A2A3
A2A3A4
```

最后：

```
长度4：
A1A2A3A4
```

因此代码通常有三层循环：

```
for (区间长度)
    for (区间左端点)
        for (分割点)
```

------

## 8. 复杂度

有三层主要循环：

```
区间长度 len
区间起点 i
分割位置 k
```

所以时间复杂度为：

```
O(n³)
```

`dp` 是一个二维数组：

```
dp[n][n]
```

因此空间复杂度为：

```
O(n²)
```

所以：

- **时间复杂度：O(n³)**
- **空间复杂度：O(n²)**

------

# 三、简易代码示例

```cpp
#include <iostream>
#include <algorithm>
#include <climits>
using namespace std;


int main()
{
    int n;
    cin >> n;


    // p数组描述矩阵大小
    // Ai = p[i-1] × p[i]
    int p[100];


    for (int i = 0; i <= n; i++)
    {
        cin >> p[i];
    }


    int dp[100][100];


    // 一个矩阵不需要乘法
    for (int i = 1; i <= n; i++)
    {
        dp[i][i] = 0;
    }


    // len表示矩阵区间长度
    for (int len = 2; len <= n; len++)
    {
        // i表示区间左端点
        for (int i = 1; i + len - 1 <= n; i++)
        {
            // j表示区间右端点
            int j = i + len - 1;


            dp[i][j] = INT_MAX;


            // 枚举分割位置k
            for (int k = i; k < j; k++)
            {
                int cost =
                    dp[i][k]
                    + dp[k + 1][j]
                    + p[i - 1] * p[k] * p[j];


                dp[i][j] = min(dp[i][j], cost);
            }
        }
    }


    cout << dp[1][n] << endl;


    return 0;
}
```

最核心的代码是：

```cpp
for (int k = i; k < j; k++)
{
    dp[i][j] = min(
        dp[i][j],
        dp[i][k]
        + dp[k + 1][j]
        + p[i - 1] * p[k] * p[j]
    );
}
```

可以把矩阵连乘的动态规划记成：

> **`dp[i][j]` 表示第 `i` 到第 `j` 个矩阵相乘的最小代价；枚举中间分割点 `k`，计算“左边最优 + 右边最优 + 左右相乘代价”，然后取最小值。**


# 旅行商问题

## 一、题目描述

旅行商问题（TSP，Traveling Salesman Problem）：

有 `n` 个城市，已知任意两个城市之间的距离。

要求旅行商：

1. 从某个城市出发。
2. **每个城市恰好访问一次**。
3. 最后回到出发城市。
4. 求总路程最短的路线。

例如有 4 个城市：

```
0、1、2、3
```

城市之间的距离为：

```
     0   1   2   3
0    0  10  15  20
1   10   0  35  25
2   15  35   0  30
3   20  25  30   0
```

一种路线为：

```
0 → 1 → 3 → 2 → 0
```

总距离：

```
10 + 25 + 30 + 15 = 80
```

旅行商问题就是要找到所有合法路线中，**总距离最短的那一条**。

------

# 二、算法分析

旅行商问题如果直接暴力枚举访问顺序，需要枚举大量排列，时间复杂度接近：

```
O(n!)
```

因此在城市数量较小时，可以使用**状态压缩动态规划**。

------

## 1. dp 的设计

我们固定：

```
城市 0 为出发城市
```

由于需要记录“哪些城市已经访问过”，可以使用一个二进制数 `S` 表示城市集合。

例如有 4 个城市：

```
S = 0101
```

表示：

```
城市0：访问过
城市1：没访问
城市2：访问过
城市3：没访问
```

也就是已经访问：

```
{0, 2}
```

定义：

```
dp[S][i]
```

表示：

> **从城市 0 出发，已经访问了集合 S 中的所有城市，并且当前停在城市 i 时的最短路程。**

例如：

```
dp[0111][2]
```

表示：

```
已经访问城市 0、1、2
并且最后停在城市 2
```

时的最短距离。

------

## 2. 初始状态

一开始只访问了城市 `0`，并且人在城市 `0`。

所以：

```
dp[1][0] = 0;
```

为什么是 `1`？

因为城市 `0` 对应二进制最低位：

```
0001
```

即：

```
1 << 0 = 1
```

所以：

```
dp[0001][0] = 0
```

------

## 3. 状态转移

假设现在：

```
dp[S][i]
```

已经计算出来。

也就是：

> 已经访问集合 `S` 中的城市，目前人在城市 `i`。

现在准备去一个**还没有访问过的城市 `j`**。

那么新状态就是：

```
S ∪ {j}
```

代码中使用位运算表示：

```
S | (1 << j)
```

于是：

```
dp[S | (1 << j)][j]
```

可以从：

```
dp[S][i]
```

转移过来。

需要增加：

```
城市 i → 城市 j
```

的距离：

```
dist[i][j]
```

所以状态转移为：

```
dp[S | (1 << j)][j]
    = min(
        dp[S | (1 << j)][j],
        dp[S][i] + dist[i][j]
      );
```

核心思想就是：

> **从已经访问过的状态出发，再选择一个没有访问过的城市加入路线。**

------

## 4. 举个简单例子

假设已经走了：

```
0 → 1
```

那么已经访问：

```
{0, 1}
```

对应二进制：

```
0011
```

假设：

```
dp[0011][1] = 10
```

现在可以继续去城市 `2`：

```
0 → 1 → 2
```

如果：

```
dist[1][2] = 35
```

那么：

```
dp[0111][2]
= dp[0011][1] + dist[1][2]
= 10 + 35
= 45
```

也可以去城市 `3`：

```
0 → 1 → 3
```

这样就不断扩展已经访问的城市集合。

------

## 5. 最终答案

当所有城市都访问过以后，状态就是：

```
111...111
```

如果有 `n` 个城市，对应：

```
(1 << n) - 1
```

例如 4 个城市：

```
1111
```

但是此时可能停在不同城市：

```
0 → ... → 1
0 → ... → 2
0 → ... → 3
```

题目还要求：

> 最后回到城市 0。

所以如果最后停在城市 `i`，还需要加上：

```
dist[i][0]
```

最终答案为：

```
min(
    dp[所有城市][i] + dist[i][0]
)
```

也就是：

> **访问完所有城市后，枚举最后一个城市，再加上返回起点的距离，取最小值。**

------

## 6. 为什么使用二进制状态

这是旅行商动态规划中最重要的地方。

如果有 `n` 个城市，每个城市只有两种状态：

```
0：没有访问
1：已经访问
```

例如：

```
10110
```

就可以表示一个城市集合。

总共有：

```
2^n
```

种不同的访问状态。

因此这种方法也叫：

> **状态压缩动态规划 / 状压 DP。**

常见位运算需要知道：

```
// 判断城市j是否访问过
S & (1 << j)


// 将城市j加入集合
S | (1 << j)
```

------

## 7. dp 思路总结

整个过程可以理解成：

```
只访问0
   ↓
访问0和一个城市
   ↓
访问0和两个城市
   ↓
访问更多城市
   ↓
访问全部城市
   ↓
回到0
```

例如：

```
0
↓
0 → 1
↓
0 → 1 → 3
↓
0 → 1 → 3 → 2
↓
0 → 1 → 3 → 2 → 0
```

动态规划会在大量可能路线中保存：

> **同一个“已访问城市集合 + 当前所在城市”情况下的最短路线。**

------

## 8. 复杂度

一共有：

```
2^n
```

种城市集合。

每个状态下可能位于：

```
n
```

个不同城市。

并且还需要枚举下一个城市：

```
n
```

所以时间复杂度为：

```
O(n² × 2^n)
```

DP 数组共有：

```
2^n × n
```

个状态，因此空间复杂度为：

```
O(n × 2^n)
```

所以：

- **时间复杂度：O(n² × 2ⁿ)**
- **空间复杂度：O(n × 2ⁿ)**

虽然仍然比较大，但是相比暴力枚举的 `O(n!)` 已经快了很多。

------

# 三、简易代码示例

下面使用状态压缩 DP 实现：

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;


const int INF = 1e9;


int main()
{
    int n;
    cin >> n;


    // dist[i][j]表示城市i到城市j的距离
    vector<vector<int>> dist(n, vector<int>(n));


    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n; j++)
        {
            cin >> dist[i][j];
        }
    }


    // 一共有2^n种城市访问状态
    int total = 1 << n;


    vector<vector<int>> dp(
        total,
        vector<int>(n, INF)
    );


    // 初始状态：只访问城市0
    dp[1][0] = 0;


    // 枚举所有访问状态
    for (int S = 0; S < total; S++)
    {
        // 枚举当前所在城市i
        for (int i = 0; i < n; i++)
        {
            // i必须已经访问过
            if (!(S & (1 << i)))
                continue;


            // 枚举下一个城市j
            for (int j = 0; j < n; j++)
            {
                // j已经访问过，跳过
                if (S & (1 << j))
                    continue;


                // 将j加入访问集合
                int newS = S | (1 << j);


                dp[newS][j] = min(
                    dp[newS][j],
                    dp[S][i] + dist[i][j]
                );
            }
        }
    }


    // 所有城市均已访问
    int all = (1 << n) - 1;


    int ans = INF;


    // 枚举最后停留的城市
    for (int i = 1; i < n; i++)
    {
        ans = min(
            ans,
            dp[all][i] + dist[i][0]
        );
    }


    cout << ans << endl;


    return 0;
}
```

其中最核心的代码是：

```cpp
int newS = S | (1 << j);


dp[newS][j] = min(
    dp[newS][j],
    dp[S][i] + dist[i][j]
);
```

含义就是：

> **已经访问集合 `S`，现在位于城市 `i`，接下来访问一个没去过的城市 `j`，把 `j` 加入集合，并更新到达 `j` 的最短距离。**

旅行商问题可以一句话记忆为：**用二进制记录“哪些城市去过”，用 `dp[S][i]` 表示“访问了集合 S 并停在城市 i 的最短距离”，不断加入新城市，最后再从最后一个城市返回起点。**


# 扔鸡蛋问题
## 一、题目描述

有 `K` 个鸡蛋和一栋 `N` 层的大楼。

存在一个临界楼层 `F`：

- 从 **F 层及以下**扔鸡蛋，鸡蛋不会碎。
- 从 **F 层以上**扔鸡蛋，鸡蛋一定会碎。

现在要求：

> 在最坏情况下，至少需要扔多少次鸡蛋，才能确定临界楼层 `F`。

例如：

```
2 个鸡蛋
6 层楼
```

我们需要设计一种扔鸡蛋的方法，使得无论临界楼层在哪里，都能够用尽可能少的次数确定它。

需要注意：

> 鸡蛋如果没碎，可以继续使用；如果碎了，这个鸡蛋就不能再用了。

------

# 二、算法分析

## 1. dp 的设计

定义：

```
dp[k][n] = 有 k 个鸡蛋、n 层楼时，
           最坏情况下确定临界楼层所需要的最少次数
```

例如：

```
dp[2][6]
```

表示：

> 有 2 个鸡蛋，需要判断 6 层楼的临界楼层，最少需要扔多少次。

------

## 2. 假设从第 x 层扔鸡蛋

假设当前有：

```
k 个鸡蛋
n 层楼
```

我们选择从第 `x` 层扔一个鸡蛋。

扔完以后有两种情况。

### 情况一：鸡蛋碎了

说明临界楼层一定在：

```
1 ～ x-1
```

之间。

因为一个鸡蛋已经碎了，所以只剩：

```
k - 1 个鸡蛋
```

需要继续检查：

```
x - 1 层
```

因此需要：

```
dp[k - 1][x - 1]
```

次。

------

### 情况二：鸡蛋没碎

说明临界楼层一定在：

```
x ～ n
```

上面继续查找。

鸡蛋没有碎，所以还是：

```
k 个鸡蛋
```

而需要继续检查上面的：

```
n - x 层
```

因此需要：

```
dp[k][n - x]
```

次。

------

## 3. 为什么要取 max

从第 `x` 层扔一次以后：

```
碎了：   dp[k-1][x-1]
没碎：   dp[k][n-x]
```

题目要求的是：

> **最坏情况下需要多少次。**

所以必须考虑更坏的情况：

```
max(dp[k - 1][x - 1],
    dp[k][n - x])
```

而当前已经扔了一次，所以还要：

```
+ 1
```

即：

```
1 + max(
    dp[k - 1][x - 1],
    dp[k][n - x]
)
```

------

## 4. 为什么还要取 min

问题来了：

> 到底应该从第几层 `x` 开始扔？

可以：

```
从第1层扔
从第2层扔
从第3层扔
...
从第n层扔
```

我们把所有可能的 `x` 都试一遍。

对于每一个 `x`，计算它在最坏情况下需要多少次，然后选择最好的方案。

所以：

```
dp[k][n] = min(
    1 + max(
        dp[k - 1][x - 1],
        dp[k][n - x]
    )
);
```

其中：

```
x = 1, 2, ..., n
```

这里可以简单记成：

> **里面取 max，是考虑最坏情况；外面取 min，是选择最优的扔法。**

这是扔鸡蛋问题最核心的地方。

------

## 5. 举个简单例子

假设：

```
2 个鸡蛋
3 层楼
```

考虑从第 `2` 层扔。

### 如果碎了

需要检查下面：

```
第1层
```

只剩一个鸡蛋：

```
dp[1][1] = 1
```

### 如果没碎

只需要继续检查：

```
第3层
```

还有两个鸡蛋：

```
dp[2][1] = 1
```

因此从第 `2` 层扔：

```
1 + max(1, 1)
= 2
```

所以：

```
dp[2][3] = 2
```

也就是说，在最坏情况下扔 `2` 次就能确定答案。

------

## 6. 初始状态

### 没有楼层

如果：

```
n = 0
```

不需要扔：

```
dp[k][0] = 0;
```

------

### 只有一层楼

只需要扔一次：

```
dp[k][1] = 1;
```

------

### 只有一个鸡蛋

如果只有一个鸡蛋，就不能冒险从中间开始。

因为一旦鸡蛋碎了，就没有鸡蛋继续测试了。

所以只能：

```
1层 → 2层 → 3层 → ...
```

逐层向上检查。

因此：

```
dp[1][n] = n;
```

例如：

```
1个鸡蛋 + 10层楼
```

最坏情况下需要：

```
10次
```

------

## 7. 状态转移总结

核心状态转移：

```
for (int x = 1; x <= n; x++)
{
    dp[k][n] = min(
        dp[k][n],
        1 + max(
            dp[k - 1][x - 1],
            dp[k][n - x]
        )
    );
}
```

其中：

```
dp[k-1][x-1]   → 鸡蛋碎了


dp[k][n-x]     → 鸡蛋没碎


max            → 考虑最坏情况


min            → 选择最佳扔鸡蛋楼层
```

一句口诀：

> **碎了看下面，鸡蛋减一；没碎看上面，鸡蛋不减；两种情况取最大，所有楼层取最小。**

------

## 8. 复杂度

假设：

```
K 个鸡蛋
N 层楼
```

DP 状态总共有：

```
K × N
```

对于每一个状态，还需要枚举：

```
x = 1 ～ n
```

即最多 `N` 个楼层。

因此时间复杂度为：

```
O(K × N²)
```

DP 数组大小为：

```
K × N
```

所以空间复杂度为：

```
O(K × N)
```

因此：

- **时间复杂度：O(KN²)**
- **空间复杂度：O(KN)**

------

# 三、简易代码示例

```cpp
#include <iostream>
#include <algorithm>
#include <climits>
using namespace std;


int main()
{
    int K, N;
    cin >> K >> N;


    int dp[100][1000];


    // 0层楼不需要扔
    for (int k = 1; k <= K; k++)
    {
        dp[k][0] = 0;
        dp[k][1] = 1;
    }


    // 只有一个鸡蛋，只能逐层测试
    for (int n = 0; n <= N; n++)
    {
        dp[1][n] = n;
    }


    // 枚举鸡蛋数量
    for (int k = 2; k <= K; k++)
    {
        // 枚举楼层数量
        for (int n = 2; n <= N; n++)
        {
            dp[k][n] = INT_MAX;


            // 枚举从第x层扔
            for (int x = 1; x <= n; x++)
            {
                int broken = dp[k - 1][x - 1];
                int notBroken = dp[k][n - x];


                int times =
                    1 + max(broken, notBroken);


                dp[k][n] =
                    min(dp[k][n], times);
            }
        }
    }


    cout << dp[K][N] << endl;


    return 0;
}
```

最核心的代码就是：

```cpp
dp[k][n] = min(
    dp[k][n],
    1 + max(
        dp[k - 1][x - 1],
        dp[k][n - x]
    )
);
```

可以直接记成：**`dp[k][n]` 表示 `k` 个鸡蛋测试 `n` 层楼所需的最少次数；从第 `x` 层扔，碎了就变成 `k-1` 个鸡蛋检查下面 `x-1` 层，没碎就用 `k` 个鸡蛋检查上面 `n-x` 层；因为要求保证最坏情况，所以两种结果取最大，再枚举所有 `x` 取最小。**
