# 各种排序
可以把这 8 种排序先按一句话记住：

| 排序     | 核心思想                       | 平均时间复杂度 | 稳定性     |
| -------- | ------------------------------ | -------------- | ---------- |
| 插入排序 | 把当前元素插入前面已有序区间   | O(n²)          | 稳定       |
| 希尔排序 | 分组做插入排序，逐渐缩小间隔   | 通常优于 O(n²) | 不稳定     |
| 冒泡排序 | 相邻比较，大的不断往后冒       | O(n²)          | 稳定       |
| 快速排序 | 选基准，小的放左边，大的放右边 | O(n log n)     | 不稳定     |
| 选择排序 | 每次从剩余元素找最小值         | O(n²)          | 不稳定     |
| 归并排序 | 一分为二排序，再合并           | O(n log n)     | 稳定       |
| 桶排序   | 按范围分桶，各桶分别排序       | 理想 O(n)      | 视实现而定 |
| 基数排序 | 按个位、十位、百位依次排序     | O(d(n+k))      | 稳定       |

### 1. 插入排序

思想类似于**打扑克牌整理手牌**。

每次拿一个新元素，在前面已经排好序的部分中找到合适位置插进去。

例如：

```text
5  3  4  1

先看 5：      5
插入 3：      3 5
插入 4：      3 4 5
插入 1：      1 3 4 5
```

特点是代码简单，**数据基本有序时效率很好**，但数据量大时 O(n²) 较慢。

------

### 2. 希尔排序

希尔排序可以理解为：

> **插入排序的改进版。**

普通插入排序只能一步一步移动，希尔排序先设置一个较大的间隔 `gap`，把相隔 `gap` 的元素分成一组，每组进行插入排序。

例如：

```text
gap = 4
gap = 2
gap = 1
```

间隔不断减小，最后 `gap = 1` 时就是普通插入排序。

核心目的就是：

> 先让元素“大步移动”到大致正确的位置，再进行插入排序。

因此通常比普通插入排序快，但它**不是稳定排序**。

------

### 3. 冒泡排序

思想是：

> 相邻两个元素比较，如果前面比后面大，就交换。

例如：

```text
5 3 2 4
```

第一次：

```text
5和3 → 交换
3 5 2 4

5和2 → 交换
3 2 5 4

5和4 → 交换
3 2 4 5
```

一轮结束后，最大的 `5` 被“冒”到了最后。

每进行一轮，就确定一个最大的元素。

时间复杂度通常是 O(n²)，适合教学和小规模数据。

------

### 4. 快速排序

快排是面试最重要的排序算法之一。

核心思想是：

> 选一个基准值 `pivot`，把比它小的放左边，比它大的放右边，然后左右两边递归进行同样的操作。

例如：

```text
5 2 7 3 6 1
```

假设选择 `5` 作为基准：

```text
小于5       5       大于5

2 3 1       5       7 6
```

然后继续排序：

```text
1 2 3 | 5 | 6 7
```

最终得到：

```text
1 2 3 5 6 7
```

平均时间复杂度：

$O(n\log n)$

最坏情况：

$O(n^2)$

比如每次都选到最大值或者最小值作为基准。

面试可以说：

> 快排采用分治思想，通过基准元素将数组划分成左右两个部分，再递归排序，平均时间复杂度 O(n log n)。

------

### 5. 选择排序

选择排序非常直观：

> 每次从还没有排序的元素中，找到最小值，放到最前面。

例如：

```text
5 3 1 4 2
```

第一轮找到 `1`：

```text
1 | 3 5 4 2
```

第二轮从剩下的找 `2`：

```text
1 2 | 5 4 3
```

继续：

```text
1 2 3 4 5
```

它和冒泡排序的区别可以简单理解为：

**冒泡排序不停交换相邻元素；选择排序先找到最小元素，再交换。**

时间复杂度始终是：

$O(n^2)$

------

### 6. 归并排序

归并排序也是典型的**分治算法**。

思想分两步：

> **先拆，再合。**

例如：

```text
8 4 5 7 1 3 6 2
```

不断一分为二：

```text
8 4 5 7      1 3 6 2

8 4   5 7    1 3   6 2

8 4 5 7 1 3 6 2
```

单个元素天然有序，然后两个两个合并：

```text
4 8
5 7
1 3
2 6
```

继续合并：

```text
4 5 7 8
1 2 3 6
```

最后：

```text
1 2 3 4 5 6 7 8
```

时间复杂度稳定为：

$O(n\log n)$

但通常需要额外 O(n) 的辅助空间。

------

### 7. 桶排序

桶排序和前面的比较排序不太一样。

思想是：

> 根据数据范围，把元素放到不同的“桶”里，每个桶内部再排序，最后按桶的顺序拼接。

例如成绩：

```text
12 35 26 78 45 91 63
```

可以按照十位分桶：

```text
10~19：12
20~29：26
30~39：35
40~49：45
60~69：63
70~79：78
90~99：91
```

然后依次取出：

```text
12 26 35 45 63 78 91
```

当数据**分布比较均匀、范围比较明确**时，桶排序非常快，理想情况下接近：

$O(n)$

但如果大量元素都进入同一个桶，优势就会明显下降。

------

### 8. 基数排序

基数排序主要用于**整数等可以按位拆分的数据**。

思想是：

> 先按照个位排序，再按照十位排序，再按照百位排序……

例如：

```text
170 45 75 90 802 24 2 66
```

先根据**个位**排序，再根据**十位**排序，最后根据**百位**排序，最终得到：

```text
2 24 45 66 75 90 170 802
```

注意每一轮按某一位排序时必须保持稳定。

如果最大数字有 `d` 位，每一位有 `k` 种可能，那么时间复杂度通常表示为：

$O(d(n+k))$

它不像快排那样直接比较两个元素的大小，因此属于**非比较排序**。

### 面试最后总结

面试时可以这样概括：

> 插入排序是把元素逐个插入前面的有序序列；希尔排序是分组进行插入排序；冒泡排序通过相邻交换把较大元素不断移到后面；选择排序每轮选择最小元素；快速排序通过基准值进行左右划分，是典型的分治算法；归并排序先递归拆分，再合并有序序列。前面这些主要属于比较排序，而桶排序和基数排序利用数据本身的范围或位数特征进行排序，在合适条件下可以突破 O(n log n) 的比较排序下界。

# 字符串匹配算法：朴素匹配算法和KMP算法？
字符串匹配常考的就是**朴素匹配算法（BF）\**和\**KMP算法**，面试时重点说清楚：**区别在于匹配失败后，主串指针是否回退。**

### 1. 朴素匹配算法 BF

核心思想：

> 从主串的每一个位置出发，依次和模式串进行比较。

例如：

```
主串：   a b c a b c d
模式串：     a b c d
```

如果从某个位置开始匹配失败，就把模式串整体向后移动一位，重新从头比较。

伪代码思想：

```
int i = 0, j = 0;

while (i < s.size() && j < p.size()) {
    if (s[i] == p[j]) {
        i++;
        j++;
    } else {
        i = i - j + 1; // 主串回退
        j = 0;         // 模式串重新开始
    }
}
```

假设：

- 主串长度为 `n`
- 模式串长度为 `m`

最坏时间复杂度：

$\boxed{O(nm)}$

主要缺点就是：**匹配失败后，之前已经比较成功的信息全部丢弃，存在大量重复比较。**

------

### 2. KMP算法

KMP是对朴素匹配的优化。

核心思想：

> 当匹配失败时，主串指针 `i` 不回退，而是利用模式串自身的前后缀信息，让模式串指针 `j` 跳到合适的位置继续匹配。

比如：

```
已经匹配：

A B A B A C
A B A B A D
          ↑
        这里失败
```

普通匹配会重新移动主串，然后从模式串开头开始。

KMP不会让主串回退，而是根据前面：

```
A B A B A
```

自身存在的相同前缀和后缀，直接调整模式串位置继续匹配。

这就是 KMP 的关键：

$\boxed{next数组}$

------

### 3. next数组是干什么的

`next[j]` 可以理解为：

> 当模式串在第 `j` 个字符匹配失败时，`j` 应该跳到哪里继续匹配。

它利用的是模式串中：

> **最长相等前缀和后缀。**

例如模式串：

```
a b a b a
```

对于：

```
a b a b
```

它的前缀有：

```
a
ab
aba
```

后缀有：

```
b
ab
bab
```

最长相等前后缀是：

```
ab
```

长度为 `2`。

所以发生失配时，已经知道前面的 `"ab"` 可以继续利用，不需要重新从头比较。

------

### 4. KMP匹配过程

核心代码思想可以写成：

```
while (i < n && j < m) {
    if (j == -1 || s[i] == p[j]) {
        i++;
        j++;
    } else {
        j = next[j];
    }
}
```

注意这里：

```
朴素匹配：
i 回退
j 回到 0

KMP：
i 不回退
j = next[j]
```

这就是两种算法最本质的区别。

------

### 5. 时间复杂度

朴素匹配：

$\boxed{O(nm)}$

KMP：

- 构造 `next` 数组：O(m)
- 字符串匹配：O(n)

总复杂度：

$\boxed{O(n+m)}$

空间复杂度：

$\boxed{O(m)}$

主要用于保存 `next` 数组。

------

### 6. 两者区别

| 对比           | 朴素匹配 BF        | KMP            |
| -------------- | ------------------ | -------------- |
| 核心思想       | 从每个位置重新匹配 | 利用已匹配信息 |
| 主串指针       | 会回退             | 不回退         |
| 模式串指针     | 失败后重新开始     | 根据 next 跳转 |
| 是否需要 next  | 不需要             | 需要           |
| 最坏时间复杂度 | O(nm)              | O(n+m)         |
| 实现难度       | 简单               | 较复杂         |

### 面试标准回答

> 朴素字符串匹配算法是从主串的每一个可能位置开始，与模式串逐个字符比较，一旦失配，主串指针需要回退，模式串重新从头开始，因此最坏时间复杂度是 O(nm)。
>
> KMP算法对这个过程进行了优化。它利用模式串自身的最长相等前后缀信息构造 next 数组，当发生失配时，主串指针不回退，而是根据 next 数组调整模式串指针的位置，从而避免重复比较。因此 KMP 的时间复杂度可以达到 O(n+m)。
>
> 一句话记忆：**BF 是“失败就重新匹配”，KMP 是“失败后利用已经匹配的信息继续匹配”，KMP 最大的特点就是主串指针不回退。**
