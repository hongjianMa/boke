# 一次完整的DMA操作包括哪三个部分？DMA和CPU的竞争，DMA和存储
DMA 是 **Direct Memory Access，直接存储器访问**。

简单说就是：

> **让外设和内存之间直接传输数据，不需要 CPU 一次一次地搬数据。**

比如磁盘要把一大块数据读到内存。





一次完整的 DMA 操作通常可以分成三个阶段：

1. **DMA 请求阶段**：外设准备好数据后，向 DMA 控制器提出请求，DMA 控制器再向 CPU 申请总线控制权。
2. **DMA 数据传送阶段**：CPU 让出总线后，由 DMA 控制器直接控制外设和主存之间的数据传输，不需要 CPU 一条条搬运数据。
3. **DMA 结束阶段**：数据传送完成后，DMA 控制器释放总线，并通常通过中断通知 CPU，CPU 再进行后续处理。

### DMA 和 CPU 的竞争

DMA 和 CPU 主要竞争的是：

> **系统总线以及主存的访问权。**

因为 CPU 正常执行程序时需要访问主存，而 DMA 传输数据时也需要访问主存，所以二者可能发生冲突。

常见的解决方式有三种：

- **停止 CPU 访问主存**：DMA 传输期间 CPU 暂停使用总线，也叫停止 CPU 法。
- **周期窃取**：DMA 每次只占用一个或少数几个存储周期，传完一点数据后把总线还给 CPU，这是最常见的方式。
- **交替访问**：把存储周期划分给 CPU 和 DMA，二者交替访问主存。

其中最常考的是**周期窃取**：

> DMA 请求主存时，会“偷”走 CPU 的一个存储周期，因此 CPU 会短暂等待，但不需要完全停止运行。

### DMA 和存储器的关系

DMA 的核心特点就是：

> **外设和主存之间可以直接传输数据，不需要经过 CPU。**

可以理解成：

```
普通方式：

外设 → CPU → 主存
主存 → CPU → 外设
```

DMA 方式：

```
外设 ⇄ DMA控制器 ⇄ 主存
                ↑
             CPU只负责初始化
             和结束处理
```

CPU 在 DMA 开始前一般只需要告诉 DMA 控制器：

- 数据放在哪里，也就是主存起始地址；
- 要传多少数据；
- 数据传输方向，是输入还是输出。

之后 DMA 控制器自动完成数据传输。

### 面试回答

> 一次完整的 DMA 操作主要包括 DMA 请求、DMA 数据传送和 DMA 结束三个阶段。DMA 传输时由 DMA 控制器直接完成外设和主存之间的数据交换，不需要 CPU 参与每一次数据传送。由于 CPU 和 DMA 都需要访问主存，因此会竞争总线和主存访问权，常见协调方式有停止 CPU、周期窃取和交替访问，其中周期窃取方式比较常见。
