# 矩阵连乘问题：最优算法，时间复杂度（使用动态规划）
矩阵连乘问题是动态规划的经典问题。

假设有一串矩阵：

$$ A_1A_2\cdots A_n $$

矩阵乘法满足结合律，所以不同加括号方式结果相同，但计算次数可能差很多。

例如：

$$ A_1:10\times100,\quad A_2:100\times5,\quad A_3:5\times50 $$

如果：

$$ (A_1A_2)A_3 $$

计算量为：

$$ 10\times100\times5+10\times5\times50=7500 $$

如果：

$$ A_1(A_2A_3) $$

计算量为：

$$ 100\times5\times50+10\times100\times50=75000 $$

因此矩阵连乘问题的目标是：

寻找一种最优加括号方式，使矩阵乘法的标量乘法次数最少。

设矩阵 \(A_i\) 的规模为：

$$ p_{i-1}\times p_i $$

定义：

$$ dp[i][j] $$

表示计算：

$$ A_iA_{i+1}\cdots A_j $$

所需要的最少乘法次数。

如果只有一个矩阵，不需要乘法：

$$ \boxed{dp[i][i]=0} $$

对于 \(i<j\)，枚举最后一次乘法的分割位置 \(k\)：

$$ (A_i\cdots A_k)(A_{k+1}\cdots A_j) $$

那么状态转移方程是：

$$ \boxed{ dp[i][j] = \min_{i\le k<j} \left\{ dp[i][k] + dp[k+1][j] + p_{i-1}p_kp_j \right\} } $$

其中：

$$ p_{i-1}p_kp_j $$

就是左右两个矩阵最终相乘的计算量。

计算顺序要按照区间长度从小到大：

for (int len = 2; len <= n; len++) {
    for (int i = 1; i + len - 1 <= n; i++) {
        int j = i + len - 1;
        dp[i][j] = INF;

        for (int k = i; k < j; k++) {
            dp[i][j] = min(
                dp[i][j],
                dp[i][k] + dp[k + 1][j]
                + p[i - 1] * p[k] * p[j]
            );
        }
    }
}

时间复杂度方面，有三层循环：

枚举区间长度：\(O(n)\)
枚举起点：\(O(n)\)
枚举分割点：\(O(n)\)

所以总时间复杂度：

$$ \boxed{O(n^3)} $$

需要一个二维 DP 数组，因此空间复杂度：

$$ \boxed{O(n^2)} $$

面试可以直接回答：

矩阵连乘问题是利用动态规划寻找最优括号化方案，使标量乘法次数最少。定义 \(dp[i][j]\) 表示矩阵 \(A_i\) 到 \(A_j\) 连乘的最小计算量，然后枚举分割位置 \(k\)，状态转移为 \(dp[i][j]=\min(dp[i][k]+dp[k+1][j]+p_{i-1}p_kp_j)\)。按照区间长度从小到大计算，时间复杂度为 \(O(n^3)\)，空间复杂度为 \(O(n^2)\)。

> `p[i - 1] * p[k] * p[j]` 表示的是：**当我们把矩阵链在位置 `k` 处分成左右两部分后，这两部分最终相乘时需要进行的标量乘法次数。**
>
> 假设：
>
> $A_iA_{i+1}\cdots A_k$
>
> 这一部分最终得到的矩阵大小是：
>
> $p_{i-1}\times p_k$
>
> 而右边：
>
> $A_{k+1}\cdots A_j$
>
> 最终得到的矩阵大小是：
>
> $p_k\times p_j$
>
> 那么两个矩阵相乘：
>
> $(p_{i-1}\times p_k)\times(p_k\times p_j)$
>
> 需要的标量乘法次数就是：
>
> $\boxed{p_{i-1}\times p_k\times p_j}$
>
> 比如有三个矩阵：
>
> $A_1:10\times100$$A_2:100\times5$$A_3:5\times50$
>
> 那么维度数组就是：
>
> ```
> p = [10, 100, 5, 50]
> ```
>
> 如果计算：
>
> $(A_1A_2)A_3$
>
> 先算：
>
> $A_1A_2$
>
> 得到一个：
>
> $10\times5$
>
> 的矩阵。
>
> 然后这个 `10×5` 的矩阵和 `A3` 的 `5×50` 相乘：
>
> $(10\times5)(5\times50)$
>
> 这一部需要：
>
> $10\times5\times50=2500$

>
> 在公式里就是：
>
> $p[i-1]\times p[k]\times p[j]$
>

>
> $i=1,\quad k=2,\quad j=3$

>
> $p[0]\times p[2]\times p[3]$
>

>
> $10\times5\times50=2500$
>

>
> $dp[i][k]+dp[k+1][j]+p[i-1]p[k]p[j]$
>
> 可以直接理解成：
>
> > **左半部分自己算完的最小代价 + 右半部分自己算完的最小代价 + 左右两部分最后乘在一起的代价。**

# 0-1背包问题：时间复杂度（使用动态规划）
0-1 背包问题是动态规划的经典问题。

假设有 `n` 个物品，每个物品都有：

- 重量 `w[i]`
- 价值 `v[i]`

背包容量为 `W`。

每个物品只有两种选择：

> **选一次，或者不选。**

所以叫 **0-1 背包**。

定义：

$dp[i][j]$

表示：

> 前 `i` 个物品，在背包容量为 `j` 时，能够获得的最大价值。

对于第 `i` 个物品，有两种情况。

如果放不下：

$j < w[i]$

那么：

$dp[i][j]=dp[i-1][j]$

如果放得下，可以选择“不放”或者“放”：

$\boxed{ dp[i][j] = \max \left( dp[i-1][j], dp[i-1][j-w[i]]+v[i] \right) }$

其中：

- `dp[i-1][j]`：不选择第 `i` 个物品。
- `dp[i-1][j-w[i]] + v[i]`：选择第 `i` 个物品。

例如：

```
for (int i = 1; i <= n; i++) {
    for (int j = 0; j <= W; j++) {
        dp[i][j] = dp[i - 1][j];

        if (j >= w[i]) {
            dp[i][j] = max(
                dp[i][j],
                dp[i - 1][j - w[i]] + v[i]
            );
        }
    }
}
```

有两层循环：

- 枚举 `n` 个物品。
- 枚举容量 `W`。

所以时间复杂度为：

$\boxed{O(nW)}$

二维 DP 的空间复杂度为：

$\boxed{O(nW)}$

还可以把二维 DP 优化成一维：

```
for (int i = 1; i <= n; i++) {
    for (int j = W; j >= w[i]; j--) {
        dp[j] = max(
            dp[j],
            dp[j - w[i]] + v[i]
        );
    }
}
```

此时空间复杂度优化为：

$\boxed{O(W)}$

时间复杂度仍然是：

$\boxed{O(nW)}$

这里有一个非常重要的点：

> **0-1 背包使用一维 DP 时，容量 `j` 必须从大到小枚举。**

因为如果从小到大枚举：

```
dp[j] ← dp[j - w[i]]
```

`dp[j-w[i]]` 可能已经在本轮被第 `i` 个物品更新过，这样相当于同一个物品可以被选择多次，就变成了**完全背包**。

### 面试标准回答

> 0-1 背包问题中，每个物品只能选择一次或者不选择。动态规划可以定义 `dp[i][j]` 表示前 `i` 个物品在容量为 `j` 时能够获得的最大价值。对于第 `i` 个物品，可以选择不放，也可以在容量足够时放入，因此状态转移为 `dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])`。由于需要枚举所有物品和所有背包容量，所以时间复杂度是 $O(nW)$，二维 DP 空间复杂度是 $O(nW)$，使用滚动数组优化后空间复杂度可以降到 $O(W)$。


# 合并K个有序链表
“合并 K 个有序链表”是一个很经典的面试题，常见做法有三种，其中最推荐回答的是 **小根堆** 或 **分治合并**。

假设一共有 `k` 个升序链表，所有链表的结点总数为 `N`。

例如：

```text
L1: 1 → 4 → 7
L2: 2 → 5 → 8
L3: 3 → 6 → 9
```

最终合并成：

```text
1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 9
```

### 1. 小根堆法

核心思想：

> 每次从 K 个链表当前的头结点中，取出最小的那个。

可以把每条链表的头结点都放入一个**小根堆**。

每次：

1. 弹出堆顶最小结点。
2. 把它接到答案链表后面。
3. 如果这个结点还有 `next`，就把 `next` 放入小根堆。
4. 重复直到堆为空。

例如一开始：

```text
L1: 1 → 4 → 7
L2: 2 → 5 → 8
L3: 3 → 6 → 9
```

堆里：

```text
1 2 3
```

取出 `1`，然后把 `4` 放进去：

```text
2 3 4
```

再取 `2`，把 `5` 放进去：

```text
3 4 5
```

依次进行即可。

C++：

```cpp
class Solution {
public:
    struct cmp {
        bool operator()(ListNode* a, ListNode* b) {
            return a->val > b->val;
        }
    };

    ListNode* mergeKLists(vector<ListNode*>& lists) {
        priority_queue<ListNode*, vector<ListNode*>, cmp> heap;

        for (auto head : lists) {
            if (head != nullptr) {
                heap.push(head);
            }
        }

        ListNode dummy(0);
        ListNode* tail = &dummy;

        while (!heap.empty()) {
            ListNode* node = heap.top();
            heap.pop();

            tail->next = node;
            tail = tail->next;

            if (node->next != nullptr) {
                heap.push(node->next);
            }
        }

        return dummy.next;
    }
};
```

因为堆中最多只有 `k` 个元素，每个结点都会进行一次入堆和出堆，因此时间复杂度：

$$
\boxed{O(N\log k)}
$$

空间复杂度：

$$
\boxed{O(k)}
$$

---

### 2. 分治法

另一种非常经典的方法是：

> 两两合并链表。

例如：

```text
L1 L2 L3 L4 L5 L6 L7 L8
```

第一轮：

```text
(L1,L2) (L3,L4) (L5,L6) (L7,L8)
```

变成 4 条链表。

第二轮：

```text
(L12,L34) (L56,L78)
```

变成 2 条。

最后再合并一次。

因为每一层所有结点总共只会被遍历一次，也就是：

$$
O(N)
$$

一共大约有：

$$
\log k
$$

层，所以：

$$
\boxed{O(N\log k)}
$$

这和归并排序的思想非常像。

---

### 3. 逐个合并

最直接的方法是：

```text
先合并 L1 和 L2
再把结果和 L3 合并
再和 L4 合并
……
```

虽然能做，但效率较低。

如果每条链表长度差不多，复杂度大致会达到：

$$
O(Nk)
$$

因此不推荐作为最优解。

### 面试标准回答

> 合并 K 个有序链表可以使用小根堆。先把每个链表的头结点放入小根堆，每次取出最小结点加入结果链表，然后把这个结点的下一个结点重新加入堆中。由于堆中最多有 K 个元素，而总共有 N 个结点，所以时间复杂度是 \(O(N\log K)\)，空间复杂度是 \(O(K)\)。另外也可以使用分治法，两两合并链表，同样可以做到 \(O(N\log K)\) 的时间复杂度。

面试记忆就是：

$$
\boxed{\text{K 个有序链表} \Rightarrow \text{小根堆 / 分治} \Rightarrow O(N\log K)}
$$


# 求数组中第K大的元素，可使用快速选择算法（基于分治思想），时间复杂度
求数组中第 K 大元素，可以用快速选择算法 Quickselect。它和快速排序一样，也使用 partition 分区，但区别是：快速排序左右两边都递归，快速选择只递归目标所在的一边。

假设数组按从小到大进行 partition，那么第 K 大元素对应的目标下标是：

$$ \boxed{target=n-k} $$

例如：

nums = [3,2,1,5,6,4]
k = 2

数组长度：

$$ n=6 $$

所以第 2 大元素对应升序下标：

$$ target=6-2=4 $$

也就是说，我们实际上是在找“排序后下标为 4 的元素”。

快速选择每次选一个 pivot，然后做 partition。partition 完以后，pivot 会处在它最终正确的位置 pivotIndex，并且满足：

左边元素 <= pivot <= 右边元素

这时比较：

pivotIndex == target

说明 pivot 就是答案。

如果：

pivotIndex < target

说明第 K 大元素一定在右边，所以左边直接舍弃。

如果：

pivotIndex > target

说明目标一定在左边，所以右边直接舍弃。

例如 partition 后：

[3,2,1,4,6,5]
       ↑
   pivot = 4
   pivotIndex = 3

而我们要找：

target = 4

因为：

$$ 3<4 $$

所以答案一定在右边：

[6,5]

左边完全不用再处理。

这就是为什么快速选择比快速排序快。

快速排序：

$$ T(n)=2T(n/2)+O(n) $$

左右两边都处理，所以平均：

$$ \boxed{O(n\log n)} $$

快速选择：

$$ T(n)=T(n/2)+O(n) $$

每次只处理一边，所以平均计算量：

$$ n+\frac n2+\frac n4+\frac n8+\cdots $$

这是等比数列：

$$ <2n $$

因此平均时间复杂度为：

$$ \boxed{O(n)} $$

最坏情况下，如果每次选的 pivot 都很差，只能排除一个元素，例如：

$$ n+(n-1)+(n-2)+\cdots $$

那么最坏时间复杂度是：

$$ \boxed{O(n^2)} $$

面试时可以直接回答：

求数组中第 K 大元素可以使用快速选择算法。它通过 partition 把 pivot 放到最终正确的位置，然后比较 pivot 的下标和第 K 大对应的目标下标。如果目标在左边，就舍弃右边；如果目标在右边，就舍弃左边，只递归其中一侧。因此平均情况下问题规模不断缩小，总代价为 \(n+n/2+n/4+\cdots\)，所以平均时间复杂度是 \(O(n)\)，最坏情况下是 \(O(n^2)\)。


# 最长公共子序列（计算子序列长度，用动态规划，时间复杂度）
最长公共子序列，也就是 LCS（Longest Common Subsequence），经典做法是动态规划。

先注意一点：子序列不要求连续，只要求相对顺序不变。

例如：

s1 = "abcde"
s2 = "ace"

最长公共子序列是：

"ace"

长度为：

$$ \boxed{3} $$

定义：

$$ dp[i][j] $$

表示：

字符串 s1 的前 i 个字符和字符串 s2 的前 j 个字符的最长公共子序列长度。

如果当前两个字符相等：

$$ s1[i-1]=s2[j-1] $$

那么这个字符可以加入公共子序列：

$$ \boxed{dp[i][j]=dp[i-1][j-1]+1} $$

如果当前两个字符不相等：

$$ s1[i-1]\ne s2[j-1] $$

那么至少有一个字符不能选，所以取两种情况最大值：

$$ \boxed{dp[i][j]=\max(dp[i-1][j],dp[i][j-1])} $$

初始条件：

$$ dp[0][j]=0,\quad dp[i][0]=0 $$

因为只要有一个字符串长度为 0，公共子序列长度就是 0。

代码可以写成：

int longestCommonSubsequence(string s1, string s2) {
    int n = s1.size();
    int m = s2.size();

    vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (s1[i - 1] == s2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    return dp[n][m];
}

假设两个字符串长度分别为 n 和 m，需要遍历整个二维 DP 表，因此时间复杂度是：

$$ \boxed{O(nm)} $$

二维数组空间复杂度是：

$$ \boxed{O(nm)} $$

如果只要求 LCS 长度，可以用滚动数组优化到：

$$ \boxed{O(\min(n,m))} $$

空间。

面试怎么回答

最长公共子序列可以使用动态规划解决。定义 dp[i][j] 表示两个字符串前 i 个字符和前 j 个字符的最长公共子序列长度。如果当前两个字符相等，那么 dp[i][j] = dp[i-1][j-1] + 1；如果不相等，则 dp[i][j] = max(dp[i-1][j], dp[i][j-1])。假设两个字符串长度分别为 n 和 m，则时间复杂度是 \(O(nm)\)，空间复杂度是 \(O(nm)\)。
