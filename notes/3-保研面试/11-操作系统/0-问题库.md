## 动态链接和静态链接的区别
简单区分：

- 静态链接

  ：程序运行前，就把需要的库代码复制并合并到可执行文件中。

  - 优点：运行时不依赖外部库。
  - 缺点：可执行文件较大，多个程序会重复保存相同库代码。

- 动态链接

  ：程序运行时，需要某个库时再加载或链接对应的动态库，如 Windows 的 

  ```
  .dll
  ```

  、Linux 的 

  ```
  .so
  ```

  。

  - 优点：节省磁盘和内存，多个程序可以共享库。
  - 缺点：运行时依赖动态库，可能出现库缺失或版本不兼容。

**面试一句话：静态链接是在运行前把库代码加入可执行文件，动态链接是在程序运行时再链接共享库。**
