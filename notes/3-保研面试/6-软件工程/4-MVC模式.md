# MVC 模式

**MVC** 是一种经典的软件架构模式，将系统分为 **Model（模型）、View（视图）、Controller（控制器）** 三部分，实现**业务逻辑、界面展示和请求处理的分离**。

### MVC 三部分分别干什么

| 组成                  | 作用                                 | Spring Boot 中的例子             |
| --------------------- | ------------------------------------ | -------------------------------- |
| **Model 模型**        | 负责数据和业务逻辑                   | Entity、Service、Repository      |
| **View 视图**         | 负责展示数据和用户界面               | HTML、Vue 前端页面               |
| **Controller 控制器** | 接收用户请求，调用业务逻辑，返回结果 | `@Controller`、`@RestController` |

可以简单记：

> **Model 管数据和业务，View 管展示，Controller 管请求。**

###  MVC 的优点

最主要的就是：

> **职责分离、降低耦合、方便维护和扩展。**

比如修改前端页面，一般不需要修改后端业务逻辑；修改业务逻辑，也不需要大幅修改页面。

### 面试推荐答案

> MVC 是一种经典的软件架构模式，包括 Model、View 和 Controller 三部分。Model 负责数据和业务逻辑，View 负责页面展示，Controller 负责接收用户请求并调用相应的业务逻辑。MVC 的主要优点是实现职责分离，降低系统耦合，提高代码的可维护性和可扩展性。

### 一句话记忆

> **MVC：Model 管数据业务，View 管页面展示，Controller 管请求调度；核心目的就是分层解耦。**
