# 软件生命周期
| 阶段       | 主要任务             | 典型输出           |
| ---------- | -------------------- | ------------------ |
| 可行性研究 | 判断项目是否值得做   | 可行性分析报告     |
| 需求分析   | 明确系统应该做什么   | 需求规格说明书SRS  |
| 总体设计   | 确定系统整体结构     | 架构设计、模块划分 |
| 详细设计   | 设计模块内部实现     | 类、接口、算法设计 |
| 编码       | 将设计转换为程序     | 源代码             |
| 测试       | 验证和确认软件质量   | 测试用例、测试报告 |
| 维护       | 修复、适应和完善系统 | 新版本、维护文档   |


## 什么是软件生命周期？
软件生命周期是指软件从需求提出、分析设计、编码测试、交付运行和维护，直到最终淘汰的整个过程。它通常包括需求分析、软件设计、编码、测试、运行维护和淘汰等阶段。

## 生命周期中哪个阶段成本最高？
在软件生命周期中，**维护**阶段的成本通常最高。因为软件投入运行后，需要**长期**进行缺陷修复、环境适配、功能扩展和性能优化，而且每次修改都可能影响已有功能，需要重新测试，因此维护工作持续时间长、复杂度高。
