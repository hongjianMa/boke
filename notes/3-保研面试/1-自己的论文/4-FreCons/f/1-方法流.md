这张图展示的是 **FreCons 的整体框架：先利用图结构学习用户和物品表示，再按频带拆分和融合信息，通过三个一致性约束稳定表示，最后计算推荐分数。**

理解这张图时，要抓住两个问题：**哪些信息值得融合，以及融合后如何保留有效信息。**

**（a）图引导的多模态学习：先获得主表示与辅助表示**

左侧输入包含物品的视觉特征、文本特征，以及用户和物品的 ID。模型从两种图结构中学习信息。

第一种是**用户—物品交互图**，也就是上面的三个 Heterogeneous 分支。图结构相同，但分别使用视觉、文本和 ID 信息进行传播。

例如，用户买过哪些商品，就可以聚合这些商品的信息；商品被哪些用户购买过，也可以聚合这些用户的信息。经过多层传播，模型还能捕获间接的协同关系。

每个模态分支得到：

- 用户表示：$\mathbf e_u^v,\mathbf e_u^t,\mathbf e_u^{id}$。
- 物品表示：$\mathbf e_i^v,\mathbf e_i^t,\mathbf e_i^{id}$。
- 用户偏好表示：$\mathbf p_u^v,\mathbf p_u^t,\mathbf p_u^{id}$。

这里需要区分：**$\mathbf p_u^m$ 是模态分支中可训练的用户偏好表示，$\mathbf e_u^m$ 是经过交互图传播后得到的用户表示。** 论文将用户偏好矩阵与物品特征一起作为图传播的初始输入。

第二种是底部的**物品—物品语义图**，也就是 Homogeneous 分支。它根据物品的多模态内容相似性连接物品，再传播信息，得到物品辅助表示 $\mathbf h_i$。

比如，两件衣服虽然没有被相同用户购买，但图片或描述相似，也可以通过语义图交换信息。

因此，进入下一模块的信息可以概括为：

| 对象 | 主表示                     | 辅助表示                     |
| ---- | -------------------------- | ---------------------------- |
| 用户 | 交互图学到的 $\mathbf e_u$ | 用户偏好 $\mathbf p_u$       |
| 物品 | 交互图学到的 $\mathbf e_i$ | 语义图增强表示 $\mathbf h_i$ |

**（b）分频带融合：拆开信息，再有选择地组合**

这一部分可以分为三个步骤。

**第一步：用 DCT 分解出低、中、高频成分。**

模型对每个模态子空间分别进行 DCT，再保留指定频带的系数，通过逆 DCT 重建对应的频带表示，最后拼接同一频带的各模态结果。

可以写成：

$\mathbf F^b = \operatorname{IDCT} \left( \mathbf M_b\odot\operatorname{DCT}(\mathbf e) \right)$

其中，$\mathbf M_b$ 是选择第 $b$ 个频带的掩码。图中的三个频带就是 $\mathbf F^l,\mathbf F^m,\mathbf F^h$。

**这里的“频率”是嵌入向量沿坐标维度的变化频率，不是用户交互频次，也不是直接对原始图片进行频率分解。**

低频对应变化较缓的分量，高频对应变化较快的分量。但不能直接断言“低频一定是有效偏好，高频一定是噪声”，不同频带的价值需要模型学习。

**第二步：在相同频带内，融合主表示和辅助表示。**

用户侧将主表示与偏好表示相加，物品侧将主表示与语义图表示相加：

$\widetilde{\mathbf F}_u^b = \mathbf F_u^b+\mathbf F_{u,a}^b$$\widetilde{\mathbf F}_i^b = \mathbf F_i^b+\mathbf F_{i,a}^b$

这就是图中的 **Dual-view residual band fusion**。

其含义是：**先把两种来源的信息分解到对应频带，再逐频带补充信息。** 用户侧补充偏好信息，物品侧补充内容相似关系。

**第三步：通过门控决定各频带的贡献。**

门控网络为每个用户或物品生成低、中、高频的调整系数：

$\mathbf g_x = \mathbf 1+\eta\,\sigma\!\left(\operatorname{MLP}(\mathbf e_x)\right), \qquad x\in\{u,i\}$

再结合全局可学习的频带权重，得到最终表示：

$\mathbf e_x^* = \sum_b w_x^b g_x^b\widetilde{\mathbf F}_x^b$

这两类权重各有作用：

- $w_x^b$：学习整个数据集上，各频带总体有多重要。
- $g_x^b$：针对具体用户或物品，进一步调整频带贡献。

下面的 **SDR 正则化**约束门控偏离中性值 $1$ 的程度，并惩罚过大的正偏移，避免少数频带被过度放大。它并不要求所有频带最终权重相同。

**（c）频率一致性学习：从三个角度约束表示**

这是方法的核心。三个损失分别回答三个不同问题：

| 损失   | 对齐什么                         | 希望解决的问题               |
| ------ | -------------------------------- | ---------------------------- |
| BandCL | 同一样本、同一频带的两次扰动表示 | 加入噪声后，表示是否稳定     |
| PrefCL | 同一用户、同一频带的不同模态偏好 | 各模态是否表达一致的用户偏好 |
| FuseCL | 同一样本的最终表示与选定频带表示 | 融合结果是否保留关键频带信息 |

**① BandCL：同一频带内部的抗噪一致性。**

对于某个频带表示，加入两份独立随机噪声，构造 $\mathbf z_1^b$ 和 $\mathbf z_2^b$。

对比学习时：

- 正样本：同一样本、同一频带的两个扰动视图。
- 负样本：其他样本在同一频带中的表示。

它要求：**同一个物品的某个频带，即使受到不同的小扰动，也应保持接近的表示。**

这里不是把低频与高频拉近，而是在每个频带内部提高稳定性。

**② PrefCL：不同模态之间的用户偏好一致性。**

对用户的三种偏好表示进行分频带处理，然后在相同频带中，两两对齐：

$id\leftrightarrow v,\qquad id\leftrightarrow t,\qquad v\leftrightarrow t$

以视觉和文本为例：

- 正样本：用户 $u$ 的视觉偏好与用户 $u$ 的文本偏好。
- 负样本：用户 $u$ 的视觉偏好与其他用户的文本偏好。

比如，同一用户对衣服的偏好，在图片中可能表现为款式，在文字中可能表现为相关描述。PrefCL 鼓励这些不同来源的信号在对应频带中形成相互支持的偏好表达。

**它对齐的是用户偏好，而非直接要求物品图片和文本特征完全相同。**

**③ FuseCL：最终融合表示与频带表示的一致性。**

经过加权融合后，一些频带的信息可能被削弱。因此，模型将最终表示 $\mathbf e_x^*$ 与该样本的选定频带增强表示 $\widetilde{\mathbf F}_x^b$ 进行对比学习。

- 正样本：同一样本的最终表示与其频带增强表示。
- 负样本：其他样本在对应频带中的表示。

它要求：**最终表示仍能对应上自身的关键频带信息，同时与其他样本保持区分。**

图中的 `pos_1` 表示自身的频带表示，`neg_1`、`neg_2` 表示其他样本的频带表示，并不是把其他频带直接当作负样本。

另外，虽然图中三个损失上下排列，**它们是联合训练的约束，不是推理时必须依次经过的三个处理层。**

**（d）预测：用最终表示进行匹配**

获得最终用户表示和物品表示后，使用内积计算分数：

$s_{ui} = (\mathbf e_u^*)^\top\mathbf e_i^*$

分数越高，表示模型认为用户越可能喜欢该物品，再按分数生成 Top-$K$ 推荐列表。

论文使用 BCE 作为推荐监督，并联合优化全部损失：

$\mathcal L = \mathcal L_{\mathrm{BCE}} +\lambda_s\mathcal L_{\mathrm{SDR}} +\lambda_b\mathcal L_{\mathrm{bandCL}} +\lambda_p\mathcal L_{\mathrm{prefCL}} +\lambda_f\mathcal L_{\mathrm{fuseCL}}$

其中，BCE 负责学习推荐目标；SDR 控制门控增幅；BandCL 保证频带抗噪稳定；PrefCL 协调跨模态偏好；FuseCL 保证最终融合表示保留关键频带信息。
